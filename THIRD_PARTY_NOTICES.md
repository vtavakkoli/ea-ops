## Archi — ArchiMate Modelling Tool

EA-Ops' built-in `archimate-3.2` profile validates legal source/relationship/target combinations against the ArchiMate 3.2 relationship matrix published by the open-source **Archi** project.

EA-Ops pins the matrix to:

- Project: https://github.com/archimatetool/archi
- Source file: `com.archimatetool.model/model/relationships.xml`
- Archi commit: `24b1f22d651d05937faa53dd9edf6128d9552dd0`
- Git blob: `5ec8c5f52a1de982f93838a28dcf1766c5e4f7ca`
- Matrix version: `3.2`
