## 0.1.0 — 2026-09-11

First public alpha of EA-Ops.

### Added
- Git-native EA repository contract using YAML objects and relationships.
- Built-in ArchiMate 3.2 starter profile with extensible metamodel loading.
- Deterministic validation for IDs, references, relationship compatibility and governance rules.
- `eaops validate`, `summary`, `impact`, `report` and `build` commands.
- Reusable GitHub Action for architecture validation.
- CI test and validation workflow.
- Static searchable architecture portal generator.
- Sample architecture report and Northstar Services reference model.
- Apache-2.0 licensing, governance, contribution and security documentation.

### Status
Alpha. The ArchiMate relationship profile is intentionally partial in v0.1.0 and does not claim complete normative conformance.
