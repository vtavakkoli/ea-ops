# Governance

EA-Ops is an open-source project developed through public issues and pull requests. The current maintainer is Vahid Tavakkoli. Decisions that materially affect the model contract, CLI compatibility or governance semantics should be documented in a pull request and discussed before merge.

The project aims to grow toward multi-maintainer governance as the contributor community grows. Maintainer status should be based on sustained, constructive contribution and demonstrated stewardship of the project.
